PROJECT TITLE
Pulse Vector: Inner Frontier

CONCEPT SUMMARY
Pulse Vector: Inner Frontier is an original Unity 3D action-adventure game inspired by classic micro-mission sci-fi. A specialized medical crew pilots a miniaturized bio-ship through a living human body to stop a cascading neural failure. The mission is short, intense, and designed for replayability through branching routes, changing hazards, and upgrade-driven gameplay.

This is not a remake of any existing film. It is a new game concept that borrows broad genre themes only: miniaturization, time pressure, and biological traversal.

GENRE AND FORMAT
- Genre: Sci-fi Action Adventure + Vehicle Combat + Light Tactical Strategy
- Camera: Third-person follow camera (ship-focused)
- Engine: Unity 3D (URP recommended)
- Mode: Single-player (core), co-op optional post-launch
- Session length: 25 to 40 minutes per run

HIGH-LEVEL PILLARS
1. Time-critical navigation through dynamic biological environments.
2. Tactical ship systems management under pressure.
3. Cinematic set pieces driven by anatomy-based hazards.
4. Meaningful progression through modules, pilot perks, and route decisions.

GAMEPLAY LOOP
1. Briefing: Choose crew loadout and ship modules.
2. Insertion: Enter bloodstream at one of multiple entry points.
3. Traverse: Pilot through arteries, heart turbulence, lung oxygen zones, and neural corridors.
4. Solve and Survive: Handle immune threats, clot barriers, electrical storms, and system malfunctions.
5. Operation: Execute precision sequence at target lesion.
6. Extraction: Escape before re-expansion timer ends.
7. Debrief and Upgrade: Spend mission rewards to unlock new modules and challenge tiers.

CORE SYSTEMS
- Ship Flight
  - Arcade-sim hybrid controls with boost, brake, roll, and micro-stabilization.
  - Collision damage based on speed and obstacle density.

- Systems Management
  - Four ship systems: Propulsion, Shields, Sensors, Surgical Array.
  - Power routing mechanic: boost one system while weakening another.

- Threat Model
  - Reactive immune entities (macro-phage swarms, antibody nets).
  - Environmental hazards (pulse surges, pressure spikes, clot fragmentation).
  - Scripted crisis events (oxygen loss, comms blackout, EMP-like bioelectric pulse).

- Objective Design
  - Main objective plus optional side goals (collect bio-data, rescue nanodrones, map anomalies).
  - Dynamic objective order on higher difficulties.

- Progression
  - Persistent upgrades between runs.
  - Examples: shield harmonics, plasma cutter efficiency, extraction thruster cooldown.

LEVEL STRUCTURE (SHORT CAMPAIGN)
- Mission 1: Arterial Descent (tutorial + core controls)
- Mission 2: Cardiac Maelstrom (timed turbulence + pressure gates)
- Mission 3: Pulmonary Refit (oxygen and stealth sections)
- Mission 4: Neural Corridor (precision navigation + electric hazards)
- Mission 5: Lesion Strike and Extraction (boss-style finale)

TECH RECOMMENDATION FOR YOUR INSTALLED UNITY 3D
- Unity Version: 2022 LTS or newer
- Render Pipeline: URP for high quality/performance balance
- Input: New Input System package
- AI/State Logic: Behavior trees or lightweight finite state machines
- Audio: Unity Audio Mixer + snapshot transitions
- Cinematics: Timeline + Cinemachine
- Save System: JSON local save with ScriptableObject-backed config
